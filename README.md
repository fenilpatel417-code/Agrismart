# AgriSmart - AI Crop Disease Detection





\# 🌾 AgriSmart — AI Crop Disease Detection



An AI-powered agricultural assistant built with FastAPI and Google Gemini 2.5 Flash.



\## 🚀 Features

\- 🦠 Crop disease detection from images

\- 🌿 Crop identification

\- 📈 Growth optimization tips

\- 💊 Treatment plans

\- 🧪 Fertilizer recommendations

\- 🤖 AI chatbot for farming advice



\## 🛠️ Tech Stack

\- \*\*Backend:\*\* FastAPI, Python 3.13

\- \*\*AI:\*\* Google Gemini 2.5 Flash

\- \*\*Database:\*\* SQLite + SQLAlchemy

\- \*\*Frontend:\*\* HTML, CSS, JavaScript



\## ⚙️ Setup \& Installation



1\. Clone the repository

&#x20;  git clone https://github.com/fenilpatel417-code/Agrismart.git



2\. Install dependencies

&#x20;  pip install -r requirements.txt



3\. Create a .env file and add your Gemini API key

&#x20;  GEMINI\_API\_KEY=your\_key\_here



4\. Run the app

&#x20;  uvicorn main:app --reload



5\. Open browser and go to

&#x20;  http://localhost:8000



\## 📁 Project Structure

\- main.py         → App entry point

\- routers/        → API route handlers

\- services/       → AI \& business logic

\- database/       → Database models

\- templates/      → HTML pages

\- static/         → CSS \& JS files
